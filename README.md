# Fashion-MNIST Image Classification using CNN

A PyTorch-based Convolutional Neural Network (CNN) project for classifying images from the **Fashion-MNIST dataset**.

## Project Overview

This project demonstrates image classification using a CNN trained on Fashion-MNIST. The notebook includes dataset loading, preprocessing, model construction, training, evaluation, and prediction visualization.

## Dataset & Model

- Dataset: **Fashion-MNIST**
- Framework: **PyTorch**
- Model: **Convolutional Neural Network (CNN)**
- Classes: **10 clothing categories**
- Epochs: **25**
- Batch size: **32**
- Learning rate: **0.01**
- GPU/CUDA support is configured in the notebook.

The Fashion-MNIST dataset contains grayscale images of clothing items belonging to 10 classes.

## Workflow

1. Load the Fashion-MNIST dataset.
2. Apply image preprocessing and transformations.
3. Create training and testing DataLoaders.
4. Build the CNN model using PyTorch.
5. Define the loss function and optimizer.
6. Train the model.
7. Evaluate the trained model.
8. Visualize predictions.
